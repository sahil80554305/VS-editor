Python Code Editor (VS Code Inspired)
A lightweight, desktop-based Python code editor built using Python and the Tkinter GUI framework. Inspired by the minimal layout of popular IDEs like VS Code, this application provides a clean and interactive environment for writing, managing, and executing Python scripts directly from a single interface.

Core Features
Integrated Script Execution: Features a built-in output panel that utilizes asynchronous subprocess handling to run saved Python files and display standard output (stdout) or compilation errors (stderr) instantly without leaving the editor.

Dynamic Themes & Customization: Includes a dedicated color theme menu supporting multiple visual profiles—including Light Default, Light Plus, Dark, Red, Monokai, and Night Blue—to adapt the editing environment to different lighting preferences.

File Management System: Equipped with essential file operations including creating a new file, opening existing .py scripts, saving progress, and a "Save As" dialogue for workspace organization.

Accessibility & Font Controls: Supports dynamic editor text adjustments with built-in font scaling options to increase or decrease text sizing on the fly.

Workspace Shortcuts: Fully bound with intuitive keyboard shortcuts for rapid workflow management:

Ctrl + N : New File

Ctrl + O : Open File

Ctrl + S : Save File

Ctrl + Alt + S : Save As

Ctrl + + : Increase Font Size

Ctrl + - : Decrease Font Size

Ctrl + Q : Exit Editor

Interface Layout
Top Menu Bar: Houses organized cascade menus for file operations and aesthetic theme switches, alongside quick-action buttons to clear the workspace or execute code.

Code Editor Frame: A spacious, white-backed text canvas supporting smooth vertical scrolling for seamless script writing.

Output Log Panel: A distinct bottom panel dedicated to real-time execution feedback, allowing developers to debug scripts and inspect terminal returns immediately.
